# SNAP Facebook comparison

Fresh-process bounded detector comparisons, 2 threads, seeds 42–44.
See [the protocol and interpretation](../../../docs/comparisons.md).
`source.json` records the download URL, citation and SHA-256 of the original
SNAP archive. Input edges are fetched separately and are not redistributed here.
`comparison.json` separates detector, load/import, common evaluation and process
RSS costs. Phase manifests and conservation checks accompany the two complete
workbench analyses. No ground-truth exclusive partition or full-scale competitor
speed claim is made.
